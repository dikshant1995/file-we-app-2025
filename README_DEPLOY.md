## How to Deploy
Since the automated Git tools are restricted in the current shell environment, please use the included script:

1.  **Double-click** `deploy_git.bat` in this folder.
2.  This will automatically:
    *   `git add .`
    *   `git commit` (with the final message)
    *   `git push`
